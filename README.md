# SiVy1 Portfolio

Comic/manga black-and-white portfolio built with React + Vite.

## Run locally

1. Install Node.js LTS.
2. Install dependencies:
   - `npm install`
3. Start dev server:
   - `npm run dev`

## Build

- `npm run build`
- `npm run preview`

## Deploy to GitHub Pages

1. Ensure repository name is `PORTFOLIO` or update `base` in `vite.config.js`.
2. Run:
   - `npm run deploy`

The app fetches latest repositories from `SiVy1` (forks excluded) and falls back to local data when API is unavailable.
